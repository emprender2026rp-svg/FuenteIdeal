# FuenteIdeal

FuenteIdeal es una aplicación web para probar las tipografías instaladas en tu computadora directamente sobre un diseño.

## Abrir la aplicación

La versión publicada está disponible en:

https://emprender2026rp-svg.github.io/FuenteIdeal/

## Funciones incluidas en v1.0.0

- Carga de imágenes desde el equipo.
- Sincronización de tipografías locales en Chrome y Edge para escritorio.
- Exclusión de fuentes predeterminadas del sistema.
- Búsqueda y filtros de tipografías.
- Texto editable y desplazable sobre el diseño.
- Alineación, espaciado, tamaño, peso y color.
- Efectos recto, arco y zigzag.
- Contorno general y contorno por letra utilizables al mismo tiempo.
- Varias capas de contorno y sombra.
- Modo oscuro y funcionamiento como aplicación web instalable.

## Uso local

Para que el navegador permita acceder a las tipografías instaladas, abre la aplicación desde un servidor HTTPS o local. Abrir index.html directamente como archivo puede limitar algunas funciones del navegador.

Las imágenes y las fuentes permanecen en el equipo del usuario; no se incluyen en este repositorio.

## Navegadores recomendados

Google Chrome o Microsoft Edge en una computadora de escritorio.
